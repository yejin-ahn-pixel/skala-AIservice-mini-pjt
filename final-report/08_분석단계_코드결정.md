# 단계 8 — 비교 분석 단계 실행 여부를 코드가 결정

> 변경 기록 번호: C12 · 전체 기록은 `과제1_코드변경기록.md` · 목차는 [README](README.md)

## 1. 문제 — 무엇이, 왜, 어떤 영향이 있었나
**현상**: 시스템이 1개뿐인 질문(B4)에서도 이벤트에 `AnalysisCompleted`가 나타났다. 소형 모델이 `needs_analysis=true`라고 하면 분석 LLM을 한 번 더 호출한다.
**원인**: `plan_node`가 모델의 `needs_analysis` 값을 그대로 상태에 저장했다.
**영향**: 비교할 대상이 없는데도 LLM 호출 1회 분(시간·비용)이 낭비된다.

## 2. 바꾼 파일과 이유
| 파일 | 변경 | 이유 |
|---|---|---|
| `agent/routing.py` | `decide_needs_analysis(모델 의견, 대상 목록)` | 규칙: 대상 2개 이상일 때만 분석 허용 |
| `agent/nodes/routing_nodes.py` `plan_node` | 모델 값 대신 위 함수 결과 사용, 이벤트에 `needs_analysis_model`/`needs_analysis` 기록 | 모델 의견과 최종 결정을 비교 가능하게 |
| `tests/test_needs_analysis.py` | 1개 대상→분석 호출 0회, 2개→1회 | 효과 검증 |

## 3. Before 코드 (개선 전 원본)

**원본 `agent/graph.py` plan_node의 반환부**

```python
    return {"tasks": tasks, "needs_analysis": result["needs_analysis"],
            ...}
```

## 4. After 코드 (현재)

**현재 `agent/routing.py` 47~57줄 (`decide_needs_analysis`)**

```python
def decide_needs_analysis(model_opinion: bool, targets: list[str]) -> bool:
    """[C12] 비교 분석(analysis) 단계를 실행할지 '코드'가 결정한다.

    Before: 소형 모델이 내놓은 needs_analysis 값을 그대로 믿었다.
            조사 대상이 시스템 1개뿐이어도 모델이 true라고 하면 분석 LLM을 한 번 더 호출했다
            (비교할 대상이 없는데도 시간·비용만 소모).
    After : 비교는 '대상이 2개 이상'일 때만 의미가 있으므로, 모델이 true라고 해도
            대상이 1개면 false로 바꾼다. (모델이 false라고 하면 그대로 false)
    판단 기준이 '시스템 개수'라는 확인 가능한 사실이라 코드가 게이트가 된다.
    """
    return bool(model_opinion) and len(targets) >= 2
```

## 5. 동작 원리 — 코드 읽는 순서
1. 모델이 계획과 함께 `needs_analysis`(비교 분석이 필요한가)를 내놓는다.
2. `decide_needs_analysis`가 `모델 의견 AND 대상 개수 ≥ 2`로 최종 값을 정한다. 모델이 true여도 대상이 1개면 false.
3. false면 기존 `gate_node`가 계획의 analysis task를 제거하고(`gate_removed`), `analysis_node`는 건너뛴다.

터미널 B(질문)  : `cd all_total_vue_student`  → 아래 명령 실행

```bash
curl -s -X POST http://127.0.0.1:8100/chat -H 'Content-Type: application/json' \
  -d '{"message":"payments-service 결제 응답 지연을 진단해주세요","thread_id":"m-an"}' | python3 -m json.tool | grep -E "PlanCreated|needs_analysis|AnalysisSkipped|AnalysisCompleted"
#   → 대상 1개: "needs_analysis": false (모델이 true라고 했다면 needs_analysis_model: true 와 함께 보임), AnalysisCompleted 없음
curl -s -X POST http://127.0.0.1:8100/chat -H 'Content-Type: application/json' \
  -d '{"message":"web-01 CPU 급증, auth-service 커넥션 풀도 같이 확인해줘","thread_id":"m-an2"}' | python3 -m json.tool | grep -E "needs_analysis|Analysis"
#   → 대상 2개 + 모델이 true면 분석 실행
```
